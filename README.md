# Ryota Ono Academic Homepage

Static GitHub Pages site using plain HTML and CSS.

## Files

- `index.html`: page content
- `styles.css`: layout and visual design
- `profile_zoom.webp`: optimized profile photograph
- `BCGO1.png`, `BCGO.png`: research figures
- `Ryota_Ono_CV.pdf`: downloadable CV
- `googleb3ea3a791aef016c.html`: Google site verification file

## Publish on GitHub Pages

Replace the corresponding files in the `ryotaono10/homepage` repository and commit
them to the `main` branch. GitHub Pages should update automatically after the commit.

Example:

```bash
git clone https://github.com/ryotaono10/homepage.git
cd homepage

# Copy the files in this package into the repository, then:
git add .
git commit -m "Redesign and update academic homepage"
git push origin main
```

## Notes

- The site intentionally uses no JavaScript and no external web fonts.
- The page is responsive on mobile and desktop.
- Publication links and biographical details should be checked once more before publication.
